# uptime

Внешняя проверка доступности Приборки (план v0.20). Каждые 5 минут GitHub Actions спрашивает `/health`.
Если около 2,5 минуты нет ответа `"status":"ok"`, открывается задача с меткой `outage` на владельца
и, если заданы секреты `TG_BOT_TOKEN` и `TG_CHAT_IDS` (через запятую), уходит сообщение в Telegram.
Когда Приборка снова отвечает, задача закрывается.

Расписание GitHub бывает с задержкой до 10–15 минут. GitHub выключает расписание в репозитории
без коммитов 60 дней: тогда включить его снова на вкладке Actions.
